# Creeper Industry

基于 NeoForge 的 Minecraft 信号工业模组。用传播、相位、叠加与相消驱动装置，不采用焦耳能量条。

## 波与机器

- TNT／苦力怕爆炸、机器脉冲与周期源均有有限速度。普通空间按欧氏距离衰减，普通墙体不额外阻挡或削弱。
- 连续源生成无间隔的理想正负交替三角波。设置有符号峰值、频率（每 tick 周期数）和整数波长（格）；波长也决定每周期的采样窗口数。每个窗口输出理想波形在该窗口内的平均幅值，波长为 1、2 格时输出恒为零。
- 波速为波长 × 频率，采样窗口经过一格需 `1 / (波长 × 频率)` tick。频率可设为 `1/320～8`，波长为 `1～16`；每个源的起振时刻决定相位并随存档保存，调整频率时保持相位连续。
- 创造信号源可切换独立脉冲与周期波；峰值为 0 时停止发射。脉冲采用三个衰减台阶，负幅值产生牵引。周期不大于 1 tick 的波不推动实体；普通信号波只施力，TNT／苦力怕仍在冲击到达时造成爆炸伤害。
- 生态瓶配方以带符号的 `start_amplitude` 指定正向或负向启动门槛。接收部件在方块中心叠加各路径的离散值；每次 `|A|` 比前一个台阶增加、且当前值达到指定方向的门槛，就累计一单位。一个 tick 内可以累计多次，合成相消在判定之前发生。

每维度 `SignalRuntime` 在信号波段切换或传播变化到达时统一刷新受影响的接收点，记录 tick 内各次幅值变化；信号侦测器右键读取方块中心的当前合成值。不同波速的旧、新版本各自继续在途，机器不搜索周围波源。

导管内部无损但有传播时间，只通过接口交换。空气直达和每个连通网络的一条确定性最短可行路径分别参与；不枚举回路。详细边界见 [改版说明](docs/wave_revision_implementation.md)。

## 建筑式生态瓶

生态瓶物品现在放置一个控制器，可手搭 3×3×3、5×5×5、7×7×7 三种外部尺寸：

- 控制器位于正面中央、地板上一格；波接收部件位于相对的背面同一高度。
- 地板、顶板和边框用防爆框架，其余墙面用防爆玻璃，内部保持空气。
- 只有波接收部件接收输入，库存和生产归控制器。破坏外壳使机器停机，其他方块保留。
- 控制器右键打开界面，显示结构状态与加工进度；动物／怪物类型仍可潜行右键切换产物。
- 模板与消耗品继续使用 `biosphere_cultivation` 数据配方。新增 `processing_units` 表示每份配方产物所需基础加工单位，默认 20。
- 三档结构当前分别使用基础需求、需求的一半、需求的四分之一（至少 1）；达到需求后批量检查材料与输出空间并生产。
- 无效输入暂停进度；缺材料／堵塞不积攒未来产量。更换模板或产物重置进度，区块卸载不补算离线生产。
- 控制器底面供漏斗抽取产物，其余面输入材料。外壳不是库存代理。

旧生态瓶切片不会自动删除，原控制器库存保留。旧结构需要取出物品后拆除并重建；旧非控制器切片不会掉落新的控制器物品。

## 官方模板施工

3D 打印机已接入上述三种建筑模板：

1. 放置打印机；建筑会在打印机背后展开，控制器距离打印机 2 格、高 1 格。
2. 空闲时潜行右键切换 3／5／7 尺寸。
3. 手持对应生态瓶控制器物品右键选择模板并开始。
4. 相邻容器提供所需方块和火药；每新放置一块消耗一份火药，每 tick 最多处理 4 个格子。
5. 材料不足、空间被占用、区块未加载或任务玩家离线时等待；潜行右键可暂停／继续。

施工不会清空占用区域；相同方块状态自动跳过。任务进度保存到打印机。此处是官方模板施工，任意玩家蓝图文件导入／导出仍属于后续系统。

## 波的表现

TNT／苦力怕保留原版爆炸声，波面经过玩家时播放破空声。以 CS2 C4 的空气扭曲为参考，冲击带镜头震动和径向扭曲；画面冲击强度及扭曲模糊时长随玩家位置的到达幅值平方增长，时长最多 20 秒。冲击反馈不受游戏内屏幕效果强度滑块控制。周期波由源参数在客户端重建正负峰值的传播波面；正峰较亮，负峰较暗。密集波列只选择有限波面绘制；此限制不影响服务端加工。

默认原版渲染路径，每帧最多合成 8 个可见波面。光影兼容与实际帧时需实机验证。频率达到每 tick 1 周期时不触发周期推拉。

## 代码目录

```text
src/main/java/com/secondition/creeperindustry
├─ content
│  ├─ energy
│  │  ├─ signal
│  │  └─ transmission
│  ├─ logistics
│  └─ production
├─ foundation
└─ CreeperIndustry.java
```

重点目录：

- `content/energy/signal`：信号源、传播、聚合、刷新、接收与运行时服务
- `content/energy/signal/runtime`：按维度隔离的信号运行时、访问入口与生命周期事件
- `content/energy/transmission`：导管、接口与导管网络
- `docs/design_draft.md`：当前规则、约束与设计取舍
