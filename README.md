# Creeper Industry

`Creeper Industry` 是一个基于 **NeoForge 1.21.1** 的 Minecraft 模组，核心主题是“苦力怕、爆炸、信号工程与危险工业化”。

项目当前已经有可运行原型，重点不在传统的“发电 -> 输电 -> 用电”，而在一套以“信号”为核心媒介的工业系统：

- 爆炸事件可以直接产生脉冲信号
- 机器可以产生连续信号
- 信号会在空气、方块和导管中传播、衰减、聚合
- 机器读取的是目标位置上的最终聚合结果

## 当前重点系统

### 信号系统

当前仓库里已经实现了信号系统的基础骨架：

- 爆炸脉冲信号
- 连续信号源与更新链
- 接收端刷新与局部重算
- 检测器调试显示
- 导管网络接入传播计算

信号的关键概念：

- 幅值：信号强度
- 周期：离散 tick 周期
- 波形：当前为方波
- 相位：决定当前 tick 采样结果

### 导管系统

导管不是六面漏风的通用信号方块，而是“内部无损传输网络”：

- 信号在普通介质中按曼哈顿距离衰减
- 信号在导管网络内部无损传播
- 导管只能通过“接口”与外界交换信号
- 接口不是独立方块，而是安装在导管六个面的同格挂件

当前规则下：

- 没有接口的导管，不会和空气或普通方块直接连通信号
- 只有装了接口的那一面，才能作为导管的输入/输出面
- 接口增删会触发导管网络缓存刷新与相关接收端重算

## 当前连续信号规则

连续信号当前采用离散方波采样，只支持偶数周期：

- `2 tick`
- `4 tick`
- `6 tick`
- `8 tick`

采样规则统一为：

- 前半周期为 `+A`
- 后半周期为 `-A`

例子：

- `2 tick`: `+A, -A`
- `4 tick`: `+A, +A, -A, -A`
- `6 tick`: `+A, +A, +A, -A, -A, -A`

为了避免全偶数周期下所有信号天然锁相，连续信号源现在正式带有相位：

- 相位是 `0 ~ period-1` 的离散 tick 偏移
- 相位由机器位置和源 id 稳定生成
- 同一台机器在同一位置时，相位稳定
- 不同机器通常不会默认同相

这套规则的目的：

- 保持方波定义纯净，不再为奇数周期打补丁
- 让连续信号叠加真正受相位影响
- 避免等效值长期退化成单一锁相结果

## 检测器读数

`Signal Update Detector` 当前会显示三类值：

- `equivalent_value`：等效值，表示聚合结果的等效强度
- `instantaneous`：当前 tick 的瞬时值
- `last_non_zero`：最近一次非零等效值

其中：

- 纯连续信号时，等效值来自公共周期内叠加波形绝对值的平均
- 若当前 tick 混入脉冲信号，则该 tick 按瞬时叠加结果结算

## 生态瓶系统

### Botanical Biosphere

当前已经实现 `Botanical Biosphere`（植物生态瓶）的第一版可用逻辑，供后续开发时参考：

- 方块本体是一个 `2x2x2` 的多方块结构
- 右键任意一个组成方块，都会打开同一个控制面板
- 当前界面包含 `3` 个槽位：树苗槽、骨粉槽、产出槽
- 树苗现在作为“产物模板”使用，不会在每次生产时被消耗
- 骨粉作为实际消耗品，每次成功触发生产只消耗 `1` 个
- 产物会根据树苗类型映射为对应原木，当前已支持常见树苗、红树胚轴、杜鹃花与盛开的杜鹃花

当前运作规则如下：

- 生态瓶接入现有信号系统，而不是使用炉子式“燃烧/进度条”逻辑
- 当生态瓶接收到一次导管传来的聚合信号，且该次信号满足“幅值 `> 8` 且当前瞬时值为正”时，会尝试生产
- 每次有效触发只产出 `1` 个对应原木
- 每次有效触发只消耗 `1` 个骨粉
- 同一波强信号只会在“由未触发进入触发”的那个边沿结算一次，避免持续高电平重复刷产物
- 同一游戏刻内如果多个组成块同时收到同一波信号，也只会实际结算一次产出

当前多方块与容器的实现约定：

- `2x2x2` 结构的每个组成方块都带有方块实体，用作信号接收代理和容器访问代理
- 实际库存仍集中在控制器方块（`x_part=0, y_part=0, z_part=0`）上
- 非控制器部分的菜单打开、物品访问、信号触发都会转发到控制器处理
- 这样做的目的是让导管接口和漏斗可以直接作用在结构的不同组成块上，而不需要额外的“外壳方块”逻辑

当前漏斗交互规则：

- 从生态瓶底部访问容器时，只暴露产出槽
- 因此底部漏斗只能抽走产出槽中的物品
- 输入槽（树苗、骨粉）不会被底部漏斗抽出
- 非底部方向默认只允许向输入槽插入，不允许抽走产出

当前界面状态：

- 已移除临时的“炉子燃烧”表现
- 当前界面是自定义绘制的三槽调试版 UI
- 后续如果要替换为正式美术资源，只需要继续调整 `BiosphereScreen`

当前范围说明：

- 目前只有 `Botanical Biosphere` 实现了实际生产逻辑
- `Zoological Biosphere` 和 `Monster Biosphere` 仍然只是占位方块，尚未接入各自的配方/行为系统
