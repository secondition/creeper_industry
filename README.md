
简要设计
=======

物流系统：
1、有线物流：压缩包。（矿车+机械动力纸箱）
2、无线物流：制导烟花火箭，可以追踪玩家或指定位置，单个只能携带单种物品
3、无线物流：定点投掷装置，可以将生物，物品投放到指定位置。

生产系统：
生态瓶（植物）：可以在其中培养植物。
生态瓶（动物）：可以在其中培养动物。
生态瓶（怪物）：可以在其中培养怪物。

能源：
脉冲信号：原版爆炸
连续信号（方波）：怕裂变、怕聚变

能源系统：
可在空气中传播，但是没传输一格都会削弱其幅值。
按曼哈顿距离像各个方向传输。

防爆导管可以无损传输。

机器启动条件：幅值大于机器所需值
机器效率：与频率相关
当接收的是脉冲信号时，频率为1s内接收到的脉冲次数（1tick只会有一次脉冲）
当接收到的是连续信号时，频率为方波的频率。

怕裂变和怕聚变为超限信号，因为其突破了原版1s20tick的限制，频率可以超过20

存储系统：暂无

自动化控制：考虑原版的合成器
