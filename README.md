
简要设计
=======
设定：世界的任何方块都会吸收震波。震波不可见且不可触。震波是标量波
爆炸会产生震波。超出空间承载能力的爆炸会产生虚空裂隙。虚空裂隙会完全吸收震波。
稳态魔方可以阻止虚空裂隙的产生，并且不会吸收震波。

物流系统：
1、有线物流：防爆导管+冲击波生成器
2、无线物流：苦力怕货运烟花，只能追踪玩家或带有玩家头颅的盔甲架，单个只能携带单种物品
3、无限物流：掌握虚空裂隙，无限制，直接将物品传送到目的地

生产系统：
生态瓶。。。

能源产生系统：
脉冲：火药，TNT在爆炸舱室中产生
连续：怕裂变、怕聚变

能源传输系统：
爆炸会在爆炸的位置产生一个震波波源，这个波会随着传播递减变弱。
标量波，球面传播。
依靠一个特殊的功能方块才能获取波，并驱动现实中的机器。
也就是说，这里的“能源”直接就是无线的传输，但是这个无线传输会受到“波的叠加”的影响

存储系统：暂无

自动化控制：考虑原版的合成器？？（具体未想好）
