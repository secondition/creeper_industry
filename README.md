# Creeper Industry

## 项目定位

这是一个以苦力怕、爆炸、信号工程和危险工业化为核心主题的模组项目。

当前文档用于记录项目的阶段目标、核心系统设计和已经确定的规则，作为后续代码实现的依据。  
其中能源系统是当前优先级最高、也是最需要先统一定义的部分。

## 当前开发阶段

项目目前仍处于前期设计和基础内容搭建阶段，主要目标如下：

- 先定义核心系统的规则，再进行代码实现
- 先实现可闭环的基础玩法，再逐步扩展高级机器和复杂联动
- 能源系统先从爆炸信号入手，后续再扩展到持续发信的机器

## 能源系统详细设计

### 设计目标

能源系统的核心目标不是模拟现实电网，而是构建一套围绕“爆炸信号”和“波形传播”展开的工业系统。

这套系统需要满足以下要求：

- 爆炸本身就是早期可用信号源
- 后续机器也可以成为持续信号源
- 信号可以在世界中传播、衰减、叠加
- 导管可以作为特殊的无损传播介质
- 机器根据接收到的信号决定是否启动以及如何工作

### 基本概念

每个信号至少具有两个核心属性：

- 幅值
- 频率

同时，系统内部还需要考虑：

- 波形
- 相位
- 周期

为了适配 Minecraft 基于 tick 的运行方式，系统采用离散时间模型。  
也就是说，所谓“连续信号”在实现上仍然是由多个 tick 组成的离散波形，而不是数学意义上的连续时间函数。

### 信号源

#### 1. 爆炸信号源

游戏前期的主要信号源是爆炸事件。

规则如下：

- 爆炸事件持续 1 tick
- 爆炸产生的脉冲信号会在该 tick 内完成传播和衰减
- 可以理解为在这个 tick 内“瞬间”传播到所有可达位置
- 爆炸事件的初始幅值由爆炸强度决定
- 例如闪电苦力怕的爆炸强度高于普通苦力怕，因此其初始幅值也更高

爆炸信号源的频率规则如下：

- 原版爆炸事件产生的是脉冲信号
- 爆炸信号统一视为周期为 1 tick、频率为 1 的脉冲信号
- 同一信号源如果在同 1 tick 内发生多个爆炸事件，仍视为频率为 1 的信号

#### 2. 机器信号源

随着游戏阶段推进，后续添加的机器也会成为信号源。

这类信号源的设计原则如下：

- 机器信号与爆炸信号分开设计
- 机器通常产生离散的连续方波信号
- 机器信号将在后续内容中进一步细化

### 传播规则

#### 1. 普通介质传播

信号在普通世界中的传播不区分空气、墙体或其他普通方块。  
只要不是导管，就统一视为普通介质。

规则如下：

- 信号可以穿墙传播
- 在普通介质中每传播 1 格，幅值固定衰减 1
- 传播距离按曼哈顿距离计算

也就是说，在普通介质中的传播代价为：

`|dx| + |dy| + |dz|`

若一个信号源的初始幅值为 `A`，到目标点的传播代价为 `d`，则到达目标点时的有效幅值为：

`A - d`

当有效幅值小于等于 0 时，视为该信号无法对目标点产生有效影响。

#### 2. 导管传播

防爆导管是特殊传播介质，其定位更接近“光缆”而不是普通电缆。

规则如下：

- 只有沿导管连通的路径才算导管传播
- 导管内部传播无损
- 导管可以与普通介质传播耦合

这意味着信号可以按以下方式传播：

- 普通介质 -> 导管入口 -> 导管网络 -> 导管出口 -> 普通介质

导管的作用不是改变信号本身，而是降低传播损耗。  
它不会改变频率、波形或相位，只会改变信号传播到目标点时所经历的衰减成本。

### 传播更新机制

能源系统采用“信号变化时更新”的设计，而不是所有机器每 tick 主动轮询。

当前确定的原则如下：

- 只有在信号源发生更新时，才重新计算相关位置的信号结果
- 只有在信号网络发生变化时，才重新计算相关位置的信号结果
- 生产机器在信号网更新时读取一次结果，并据此调整自身状态

会触发更新的情况包括但不限于：

- 爆炸事件发生
- 持续发信机器的输出变化
- 导管被放置、破坏或导致网络连通性变化

### 多信号叠加

这是本系统最核心的部分之一。

#### 1. 叠加对象

对于某个需要计算的坐标，系统会收集所有能够传播到该位置、且有效幅值大于 0 的信号。  
这些信号在该位置不会作为“多路独立结果”长期保留，而是会叠加为一个新的单一信号。

机器默认只读取这个最终合成后的单一信号。

后续可以设计特殊机器，用于拆解或分析多频段成分，但这不影响当前基础规则。

#### 2. 叠加规则

信号叠加时需要考虑：

- 不同频率会共同生成一个新的信号
- 相位是有意义的
- 波形当前统一按方波考虑

系统不会简单地“按频率分组后取最大值”，而是要先形成新的叠加波形，再从这个新波形中提取结果。

#### 3. 新信号的周期与频率

多个信号叠加后，新信号的频率由参与叠加的频率共同决定。

当前约定为：

- 新信号的共同周期按参与叠加信号周期的最小公倍数来确定
- 新信号的频率由该共同周期决定

为了便于离散 tick 系统实现，可以等价地理解为：

- 先根据各信号周期求出共同周期
- 再以这个共同周期作为新波形的计算周期

这部分在实现时更适合使用“周期”而不是直接使用“频率”作为内部表示。

#### 4. 新信号的幅值

在求出新信号的周期后，需要在这个周期内观察叠加结果的幅值变化。

规则如下：

- 幅值允许有正负
- 最终取的是该周期内幅值绝对值的平均值
- 这个平均值只看数值大小，不关心符号

也就是说，最终机器读取到的幅值，是叠加后新波形在一个完整周期内的平均绝对值。

#### 5. 脉冲信号参与叠加时的特殊规则

上述“共同周期 + 周期内平均绝对值”规则，只适用于参与叠加的信号在观测窗口内持续有效的情况。  
因此，它适用于连续信号之间的叠加，不直接适用于仅持续 1 tick 的脉冲信号。

当某个 tick 内存在脉冲信号参与叠加时，规则改为：

- 该 tick 不构造跨 tick 的新共同周期
- 连续信号先按各自相位取该 tick 的瞬时值
- 再与该 tick 内有效的脉冲信号一起做带符号叠加
- 叠加顺序始终是“先求和，再取绝对值”
- 该 tick 交给机器读取的结果为该 tick 的瞬时等效幅值 `|sum|`

这意味着：

- 脉冲信号在其有效 tick 内可以与连续信号发生真实叠加
- 但不会把一个只持续 1 tick 的扰动扩展为跨多个 tick 持续存在的新周期结果
- 当脉冲结束后，系统应立即恢复为仅连续信号的稳定叠加结果

### 机器读取规则

机器默认只读取单一最终信号，而不是直接读取所有输入源。

当前规则如下：

- 机器启动条件：接收到的最终信号等效幅值大于机器所需阈值
- 机器效率：与最终信号频率相关

其中，“最终信号等效幅值”的定义为：

- 若当前参与叠加的全部为连续信号，则取共同周期内叠加波形绝对值的平均值
- 若当前 tick 内存在脉冲信号参与叠加，则取该 tick 瞬时叠加结果的绝对值 `|sum|`

也就是说，绝对值只用于机器工作判定；在此之前，所有信号仍然先按波形和相位做带符号叠加。

后续可扩展：

- 某些机器只对特定频率范围响应
- 某些机器可以拆解复合信号
- 某些机器可以放大、衰减、变换或调制信号

### 超限信号

“怕裂变”和“怕聚变”对应的连续信号属于超限信号。

当前约定如下：

- 它们突破了原版 1 tick 1频率的限制

这类信号属于后续中后期系统内容，但设计上需要提前为高频信号预留空间。

## 设计取舍

### 当前推荐的实现方向

根据当前规则，能源系统更适合采用“按需计算目标坐标结果”的实现方案，而不是把信号传播结果写入大量方块状态中。

理由如下：

- 普通介质传播只依赖距离衰减，适合直接计算
- 导管网络虽然需要处理连通性，但仍更适合作为单独网络处理
- 机器数量相对可控，更新目标明确
- 信号叠加的真正复杂度在“目标点波形求值”，不在“空间逐格扩散”

### 不采用的方向

当前不建议采用以下思路作为主实现：

- 使用 BFS 将信号逐格扩散到所有普通方块
- 在大量方块属性或方块状态中直接记录信号结果

主要原因如下：

- 成本高
- 缓存失效复杂
- 与多信号叠加和导管耦合后维护难度大
- 大多数位置并不需要被实际读取

## 连续信号实现框架

当前已经基本确定，连续信号与爆炸脉冲信号共用同一套“目标点贡献 -> 统一叠加 -> 接收端读取结果”的总体结构，但在触发方式上分开设计。

### 1. 分层职责

连续信号实现分为以下几层：

1. 信号源层  
持续发信机器维护自己的原始信号定义，包括但不限于：
- 幅值
- 周期
- 相位
- 波形

2. 持续信号源仓库  
持续信号源需要进入仓库存储，用于后续按目标点进行贡献计算。  
仓库记录的是“仍然有效的持续信号源”，而不是已经传播后的结果。

3. 传播 / 求值层  
该层根据目标点坐标，结合持续信号源仓库中的源定义，计算这些源传播到目标点后的有效贡献。  
这里计算的是：
- 传播代价
- 传播后的有效幅值
- 保留原有周期、相位、波形后的目标点贡献

4. 统一叠加层  
统一叠加层不负责传播，只负责对已经到达目标点的贡献进行采样和合成。  
它会：
- 收集同一目标点、同一 tick 内的所有贡献
- 根据参与叠加信号的周期求共同周期
- 在共同周期内逐 tick 采样各贡献的瞬时值
- 计算每个采样点的叠加结果
- 对叠加结果取绝对值并求平均值
- 输出机器读取的最终幅值与周期信息

5. 接收端  
接收端或机器本身不直接遍历所有源，也不直接处理传播逻辑。  
它只读取统一叠加层给出的最终结果。

### 2. 触发方式

爆炸脉冲信号采用“源驱动”：
- 爆炸事件发生时，立刻传播到受影响目标点
- 生成目标点贡献
- 提交到统一叠加层

连续信号采用“变化驱动”：
- 当持续信号源输出发生变化时，触发一次更新
- 当导管网络或传播结构发生变化时，触发一次更新
- 当脉冲信号出现并影响到目标点时，触发一次更新
- 当该脉冲信号在下一 tick 失效时，也视为一次变化并触发重算
- 更新时，只重算受影响目标点的持续信号贡献
- 再与当前 tick 内的脉冲贡献一起进入统一叠加层

### 3. 为什么不采用“所有机器每 tick 主动轮询”

当前方向不采用“所有接收端每 tick 主动读取所有源并重新计算”的实现方式，原因如下：

- 大多数 tick 实际上没有新的爆炸信号
- 很多持续信号源在长时间内不会发生变化
- 机器数量增长后，全量轮询的成本会持续上升
- 变化驱动更符合本系统“离散事件 + 周期信号”的结构

因此，推荐的方向是：
- 脉冲信号通过事件触发传播
- 连续信号通过输出变化或网络变化触发更新
- 接收端被动接收最终结果，而不是每 tick 主动拉取
