# 信号传播与建筑机器

## 波源与传播

爆炸和创造信号源的独立脉冲使用有限的三段阶梯包络。周期源生成连续的正负交替三角波，由有符号峰值、频率与相位定义。慢波的整数波长为 1～320 格，频率为波长的倒数；快波的频率为 2～8 周期/tick，波长为频率的倒数。所有波以 1 格/tick 传播。

源启动时刻决定起振相位，频率改变时保持相位连续。峰值、频率的改变以及停机会形成传播中的版本界线；旧版本继续传播直到新版本抵达。

普通介质按欧氏距离衰减：先根据传播距离取得带符号峰值，再计算连续波形。空气和普通方块均允许传播。独立脉冲到达接收点后依次输出 `A、A/2、A/4`，各持续一个 tick，再归零。

## 路径与接收

每个维度的 `SignalRuntime` 持有源版本、已加载接收点、导管网络和待到达事件。接收点在方块中心读取信号。空气直达与每个可达导管网络的一条确定性最短路径分别抵达并参与叠加；导管内部无损，但路径长度及进出接口影响传播时间。导管只通过已安装接口与外界交换信号，拓扑变化会通知受影响接收点。

源变化可提前预告到达时间，接收点仍保留在途旧波；到达时才变更其输入。同一时刻的路径变化先合并，波形转折、每 tick 采样与不同时刻的传播变化依次结算。运行时只处理已加载接收点与到期事件。区块重新加载时从当时的波建立基线，离线期间不生产，也不会因建立基线凭空产生一次穿越。

信号侦测器右键显示当前中心的带符号值、绝对值、最近一次非零绝对值与下一次已知输入变化的预计延迟；其方块状态由到达的信号变化更新。

## 加工规则

`biosphere_cultivation` 配方使用正整数 `start_amplitude`。生态瓶的接收点先合成所有慢波和脉冲路径的带符号波形；每当最终幅值的绝对值从门槛以下升至达到门槛时，贡献一个加工单位，正负幅值都有效。同一世界 tick 内的多次跨越分别累计。快波保留在信号系统中，但不参与生态瓶加工。

接收部件只转发输入给控制器，库存与进度由控制器保存。材料不足、结构无效或输出堵塞时暂停累计；已有的未完成进度保留。换模板或选定产物后按新配方开始计算。三种生态瓶结构的加工需求分别为基础 `processing_units` 的 1、1/2、1/4，至少为 1。

## 实体与画面

机器接收端将导管路径纳入叠加。实体受力与客户端周期波面按源周围的普通空间场计算；导管出口不单独产生实体冲击或波面。频率不足每 tick 一周期的连续波，每 tick 在实体位置采样并按符号推拉；更快的连续波不推动实体。独立脉冲经过实体时施加一次冲量；普通信号波只施力，TNT 和苦力怕的爆炸伤害随冲击到达时结算。

TNT 与苦力怕保留原版爆炸声，波面经过玩家时播放破空声。客户端按慢波源参数重建正负峰值的传播波面，并以明暗区分；快波在主世界不绘制。画面冲击的强度与恢复时长随玩家位置的到达幅值平方增长，时长最多 20 秒；每帧最多合成 8 个可见波面。

## 建筑与施工

生态瓶由控制器、波接收部件和外壳组成，外部尺寸为 3×3×3、5×5×5、7×7×7。控制器位于正面中央、地板上方一格，接收部件位于背面相同高度；地板、屋顶和边框使用防爆框架，其余墙面使用防爆玻璃，内部为空气。结构破损时停机并保留方块与库存。

3D 打印机支持从相邻容器获取方块与火药，按模板逐格搭建这三种结构；遇到空间占用、材料不足、区块未加载或任务玩家离线时等待。任务与进度保存在打印机中，可暂停与继续。
