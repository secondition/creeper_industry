# 波与建筑机器改版实现说明

本文记录本次实际实现与采用的默认边界。历史讨论保留在 `wave_propagation_development.md`，不再以旧的瞬时信号、全周期绝对值平均和一次放置整座生态瓶作为当前规则。

## 已接通的链路

TNT／苦力怕爆炸与创造信号源发出的脉冲、周期波，进入按维度隔离的运行时。源变化时统一寻找受影响接收点，记录各路径的未来到达，并提前调用接收端的变化通知。到达时才替换输入，接收点先叠加带符号幅值，再给机器加工结果。旧的瞬时爆炸信号链与每个接收点每 tick 搜索全源的聚合链已移除。

信号检测器可以右键查看当前幅值与最近一次待到达变化的剩余时间；幅值保留小数，不再向上取整。接收部件只订阅信号，不自行扫描波源。零距离与新加载目标不保证提前一个完整 tick 通知。

## 数值和结算

| 项目 | 本次实现 |
| --- | --- |
| 源周期 | 0.1～1.0，步长 0.1；2～100 全偶数，共 60 档 |
| 快波边界 | 周期不大于 1 tick；1 属于小数档 |
| 相位与到达时间 | 0.05 tick；传播时间向上量化，避免提前到达 |
| 幅值计算精度 | 0.001；先带符号叠加，再取绝对值判门槛 |
| 普通空间 | 球面扩散，速度 1 格/tick，欧氏距离每格损失 1 幅值；墙体不额外衰减 |
| 方波 | 半周期 +A，半周期 −A；相位以世界时间为基准 |
| 脉冲 | 接收处到达幅值 A、A/2、A/4 各保持 1 tick，随后归零 |
| 工作门槛 | 严格大于配方需求；等于门槛不工作 |
| 纯快波 | 使用真实合成波形的最大绝对幅值与最小重复周期；完整周期达标才加 1 单位 |
| 慢波及含脉冲输入 | 当前 tick 幅值达标，且带符号合成值不同于上一 tick，才加 1 单位 |
| 快慢混合 | 按慢波规则；相消优化前决定分支，避免用取消项把混合输入升级到快波 |

同一到达时刻的输入先合并，消除处理顺序带来的假边沿。不同到达时刻各自更新；慢波最终仍受每世界 tick 至多 1 单位限制。纯快波在两个变化之间按完整周期批量计数，而非逐源计算产能。

单路达标 0.1 tick 波在稳定接收后每世界 tick 加 10 单位；0.3 tick 保留周期余量，可形成 3、3、4 的计数。多路快波的合成周期可能大于 1 tick：仍属于纯快波分支，但按较长的真实合成周期计数，不能将周期强行舍入回源档位。

### 本次自行确定的结算边界

- 真正的输入变化会重建计数基准，未完成周期舍弃；变化前已经完成的周期按当时的合成峰值结算。
- 一个世界 tick 内只要出现过慢波输入，整个 tick 保守按慢波结算，不再叠加之前的快速生产单位。
- 源停止、调幅、调周期、调相位均有传播延迟；已经发出的版本保留到达机会。
- 区块恢复时只建立当前输入基线，不制造初始边沿、不补发离线产量；使用当前已加载拓扑重建输入，不回放离线世界的完整拓扑历史。
- 缺材料、输出堵塞或结构未成型时不累计新进度；已有不足一份的进度保留。更换模板、选定产物或重新加载后的配方对象变化时重置进度。批量生产受材料与输出容量限制，超额加工单位不无限囤积。

## 导管与多路径

空气直达独立计入；每个可达连通导管网络选择一条确定性的最短可行入口／出口路径，按自身时延到达后参与叠加。导管内部不损失幅值，但内部长度与进出接口均消耗传播时间。入口前和出口后的空气段正常衰减。接口以外的导管面不交换信号。

不枚举同一网络的全部出口组合、回路或反复进出路径。单连通网络限 4096 格，超限停止该网络传输，并限频记录服务端警告；空气直达仍有效。路径缓存最多 4096 项，拓扑变化时失效。拆改导管后，已排队的旧版本按原路径完成，后续输入按新路径调度，并给消失的旧路径安排延迟截止。

导管输送目前用于机器输入；客户端周期波面与实体受力表现仍按源周围的空间场计算，没有在导管出口再生成一套波面或实体冲击场。

## 缓存与性能

- 接收端按区块建立空间索引；只有活动接收点参与 tick 结算，输入归零或完全相消时可休眠。源和拓扑改变时才查询路由。
- 等周期、等效相位的方波先合组；相差半周期的项先转换成相反幅值，从而消除相消项。
- 纯快波公共周期上限 5040 个 0.05 tick 单位，只在输入变化时编译；求出峰值与最小重复周期后，正常 tick 用整数除法结算周期数。
- 慢波不展开巨大公共周期，保存合成表达式与 32 tick 有界窗口。每 32 tick 补算窗口；含脉冲时直接计算当前样本。这里仍有随活动贡献数量增长的求值开销，并未宣称变成零成本。
- 源历史有限保留，每 200 tick 清理；保留窗口 12500 tick 覆盖当前有界最长路径。高密度爆炸和频繁修改波源仍会增加历史与到达队列内存。
- 建筑结构修改合并检测，每 tick 最多验证 16 个控制器；等待验证的机器先停机。普通框架、玻璃无机器方块实体或信号 ticker。
- 打印机每 tick 最多处理 4 个模板格，不强制加载区块。稳定配方使用缓存，实际产出批量结算，进度增加不逐次广播方块更新包。
- 周期波不按每次波峰发送网络包；客户端按源参数计算波面。渲染每帧选取最多 8 个波壳，高频波面按距离抽稀。世界场高频渲染不改变机器结算。

当前主要剩余性能风险是高分辨率的全屏深度／颜色采样、密集慢波源对大量实体的查询、频繁拓扑变更时的路径重算，以及大量同时到达造成的集中编译。尚无游戏内帧耗时或服务器 tick 压测数据，不能据此保证特定机器规模的性能。

## 实体与画面

爆炸反馈增强了空气扭曲、径向模糊和镜头震动，反馈参数不再受游戏的屏幕效果强度滑块控制。正负脉冲产生相反的径向作用，周期波的正负阶段分别推／拉；小数档周期源不造成实体推拉或伤害。负幅值不让波面倒着传播。

机器慢周期场会先合并同一实体处的周期输入，再根据变化产生受力与伤害。爆炸／独立脉冲仍各自记录首次壳面命中，不让三个尾部台阶造成三次爆炸伤害；实体层尚未把独立脉冲与周期场统一为一条合成受力曲线。机器接收层已统一聚合这两类输入。

连续周期场目前显示空间折射波面；强烈的屏幕受击反馈由脉冲触发，避免小数档周期源持续震屏。原版渲染是本轮基准，没有完成光影模组兼容验证。

## 建筑与施工操作

生态瓶变为单格控制器，外部尺寸选 3×3×3、5×5×5、7×7×7。正面中央、地板上方一格放控制器，背面相同位置放波接收部件；地板、屋顶、边框用防爆框架，其余墙面为防爆玻璃，内部为空气。库存、漏斗接入和生产只归控制器。结构破损即停机，不删除剩余方块。

配方的 `processing_units` 为基础加工需求，默认 20，范围 1～30000。三种尺寸的需求分别按 1、2、4 作除数，向下取整且至少为 1。这些是可继续调整的原型平衡值，不是已完成的科技解锁树。

3D 打印机空闲时潜行右键切换尺寸；手持对应控制器右键启动官方模板。打印机背后两格、上方一格是控制器位置，建筑继续向后展开。相邻容器提供方块和火药，每放置一格消耗对应方块与 1 火药。相同状态的已有方块跳过，遇到占用、缺料或未加载区块时等待；潜行右键暂停／继续。任务保存到打印机，玩家离线时停止施工。

本次施工入口是模组官方预设模板，未实现任意玩家蓝图文件导入、导出或完整跨模组方块数据复制。创造源直接开放全部周期档位，正式科技解锁另属内容扩展。

旧生态瓶的坐标状态仍保留以找到原库存控制器；不会自动清理旧组成块。旧切片不再产出新的控制器物品，需要取出库存后人工拆除并按新建筑重建。
